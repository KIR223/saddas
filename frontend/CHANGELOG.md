# Changelog — МелМК frontend

## 2.0.0 — 2026-10-07

### Добавлено
- Спокойный первый экран: приветствие, «Сейчас/Дальше» с кольцом прогресса, пары на сегодня
- Вкладка **Звонки** (таймлайн, перемены, текущая пара, сокращённый день, кураторский час)
- Поиск групп во вкладке расписания + bottom-sheet (избранные / недавние)
- Глобальный поиск с нормализацией (е/ё, дефисы, токены), подсветкой и группами результатов
- Кураторский час (пн/чт), настройка в админке, учёт в «Сейчас»
- Админка `/admin`: PBKDF2-вход, замены с датами, редактор звонков, Excel/экспорт, журнал
- Темы: светлая/тёмная + 10 настроений (`css/moods/*`), кнопка палитры в шапке
- `css/animations.css`, `css/melmk-ui.css`, ленивые mood-стили
- Бейдж типа недели (зелёная/красная) без переключателя

### Изменено
- Нижняя навигация: Расписание, Звонки, Поиск, Преподаватели, Кабинеты
- Тема по умолчанию всегда светлая (без `prefers-color-scheme`)
- Замены поддерживают период дат и автоснятие после окончания

### Удалено
- Переключатель зелёной / красной недели из публичного UI
- Кнопка «Поделиться» из тулбара расписания
- Пункт «Админ» из нижней навигации и аккордеон звонков в шапке

### Безопасность
- Логин/пароль админки сравниваются по PBKDF2-SHA256 (200k); в исходниках только соль и хэш
- Блокировка после 5 попыток, сессия 20 мин; README честно описывает пределы frontend-only защиты
