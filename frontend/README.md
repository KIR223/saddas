# МелМК — расписание (frontend PWA)

Студенческий интерфейс расписания МелМК: спокойный первый экран, звонки, поиск, темы-настроения, PWA. Админка только по адресу `/admin`.

## Запуск

Нужен статический HTTP-сервер (ES-модули и SW не работают с `file://`).

```bash
# из корня репозитория (nginx + frontend)
docker compose up

# или только frontend
npx --yes serve -l 8080 frontend
# → http://localhost:8080
# → http://localhost:8080/admin/
```

Данные подтягиваются с API (если доступен) и кэшируются в IndexedDB/localStorage. Выдуманных групп нет: при отсутствии данных — пустое состояние.

## Админка `/admin`

В публичном UI нет ссылок на админку.

1. Откройте `/admin/`
2. Логин: `melmk_admin`
3. Пароль задаётся при сборке; в коде хранятся только **соль и PBKDF2-хэш** (`js/config.js`)

### Честно о безопасности

На чистом фронтенде это **защита от случайного входа**, а не настоящая безопасность: хэш виден в исходниках, любой может обойти UI. Для реальной защиты нужен сервер (HTTP Basic / сессии / JWT).

### Смена пароля / логина

В консоли браузера (на странице админки):

```js
import { generateHashPair } from './js/utils/auth.js';
const login = await generateHashPair('новый_логин');
const pass = await generateHashPair('новый_пароль');
console.log({ login, pass });
```

Подставьте `salt` и `hash` в `js/config.js` → `AUTH.loginSalt`, `AUTH.loginHash`, `AUTH.passSalt`, `AUTH.passHash`.

Параметры: PBKDF2-SHA256, **200000** итераций, 32 байта.

После 5 неверных попыток — блокировка на 5 минут (`localStorage`). Сессия в `sessionStorage`, автовыход через 20 минут бездействия.

## Темы и настроения

- По умолчанию: **светлая** + настроение **Индиго** (`prefers-color-scheme` не используется).
- Кнопка палитры в шапке → bottom-sheet / popover «Оформление».
- Атрибуты: `[data-theme="light|dark"]`, `[data-mood="…"]`.
- Файлы: `css/moods/<name>.css` (ленивая подгрузка).

### Как добавить новую палитру

1. Создайте `css/moods/my-mood.css` с блоками `[data-mood="my-mood"]` и тёмным вариантом.
2. Добавьте id в массив `MOODS` в `js/config.js`.
3. Добавьте кружок `.mood-card__swatch--my-mood` в `css/melmk-ui.css`.

### Как отключить анимации

1. Глобально: `ANIMATIONS_ENABLED = false` в `js/config.js`.
2. Только фон: переключатель «Анимации фона» в «Оформление» или `localStorage.melmk_mood_bg = '0'`.
3. Система: `prefers-reduced-motion: reduce` отключает анимации автоматически.

## Нижняя навигация

Расписание · Звонки · Преподаватели

При входе группа **не выбирается** — нужно выбрать самому. Виды: **День / Неделя / Месяц**.

Админка `/admin`: редактор пар по группам, замены, преподаватели, кабинеты, звонки, Excel/JSON.

Переключатель зелёной/красной недели удалён: всегда текущая неделя, тип — информационный бейдж.

## Структура

```
frontend/
  index.html          — публичный сайт
  admin/              — /admin (noindex)
  css/                — токены, layout, melmk-ui, moods/, animations
  js/
    app.js            — публичное приложение
    config.js         — флаги и хэши auth
    models/           — schedule, bells, substitutions
    views/            — экраны
    utils/            — theme, auth, search, …
    api/              — синхронизация с бэкендом
    parser/ export/   — Excel / экспорт
```

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `/` | Поиск |
| `Esc` | Закрыть sheet / очистить поиск |
| `←` `→` | День |
| `T` | Светлая ↔ тёмная |

## Ограничения

- Excel-парсер может тянуть SheetJS с CDN при разборе.
- Замены и настройки звонков хранятся локально на устройстве (пока нет серверного API замен).
