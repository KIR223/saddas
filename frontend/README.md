# Интерфейс МелМК

Статический HTML/CSS/JavaScript без сборки. Публиковать содержимое этой папки в корне HTTPS-домена. API по умолчанию `https://api.melmksch.fvds.ru`; можно задать `window.SCHEDULE_API_BASE` до загрузки модулей. Точный origin интерфейса должен быть в ALLOWED_ORIGINS сервера.

Публичный `/` не требует входа. `/admin/` — общий серверный вход: admin попадает в панель, teacher в `/teacher/`. Пароли проверяет FastAPI, cookie HttpOnly; клиентские хэши, localStorage-токены и локальные редакторы удалены. Пользователей создаёт администратор. Первый admin создаётся из env сервера — см. backend/README.md.

Админка требует сеть. Все разделы работают через API: группы, шаблон зелёной/красной недели, замены диапазоном, справочники, звонки, импорт Excel, пользователи, журнал. Успешный ответ означает запись в общей БД. Excel — только серверный .xlsx, с явным выбором режима и судьбы замен.

Публичный сайт сохраняет успешные ответы API в IndexedDB: шаблоны скачанных групп, просмотренные дни с заменами, звонки и revision. При открытии сначала показывает снимок, затем обновляет данные. Ошибки сети и некорректные ответы не стирают кэш. Ранее не открытые даты могут содержать только шаблон; это отмечено в статусе. Приватные ответы API не кэшируются.

Service Worker кэширует публичную оболочку, темы, шрифты и иконки. Обновление версии предлагает кнопкой. При добавлении публичного модуля включить его в ASSETS в sw.js и повысить CACHE. Админка не предназначена для офлайна.

Проверки из корня репозитория:

```sh
node --test frontend/tests/*.mjs frontend/js/models/bells.test.js frontend/js/utils/time.test.js
```

Инструкция установки Safari/iPhone: [PWA-iPhone](../docs/processes/PWA-iPhone.md). Реальный iPhone требует отдельного аппаратного прогона.
