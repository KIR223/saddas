# Руководство администратора МелМК

## Вход

1. Откройте `/admin/` (локально: `…/frontend/admin/`).
2. Введите логин и пароль (заданы при установке; в коде хранятся только хэши).
3. Сессия ~20 минут бездействия; после 5 неверных попыток — блокировка 5 минут.

Поисковики: `noindex, nofollow`.

## Разделы

| Раздел | Назначение |
|--------|------------|
| Главная | Счётчики, тип недели (только показ), быстрые действия |
| Расписание | Редактор пар по группам |
| Замены | Мастер замен / отмен |
| Преподаватели / Кабинеты | Справочники |
| Звонки | Сетка пар и кураторский час |
| Данные | Импорт Excel/JSON, экспорт, синхронизация с API |

## Тип недели «Зелёная» / «Красная»

Считается существующей функцией проекта. В админке **нельзя** переключать и настраивать. Только отображение.

## Импорт Excel

Раздел «Данные» → загрузка `.xlsx` / `.xls` / `.csv`. Перед заменой данных — подтверждение. Есть выгрузка JSON/CSV/ICS для отката вручную.

## Публичный сайт

После правок нажмите «Обновить» на публичной странице или дождитесь синхронизации с API (если настроена).
