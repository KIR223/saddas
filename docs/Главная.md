# MelMK-Schedule

Расписание МелМК: студенты смотрят пары в браузере и как PWA, администратор загружает Excel семестра и правит отдельные дни.

Это хранилище Obsidian описывает **текущее** устройство проекта по коду. Живая схема HTTP — интерактивная документация FastAPI (`/docs` на бэкенде), не снимок JSON.

## Два входа

| Кто | URL | Код |
| --- | --- | --- |
| Студент, преподаватель | `/` | `frontend/index.html` → `frontend/js/app.js` |
| Администратор | `/admin/` | `frontend/admin/index.html` → `frontend/admin/admin-app.js` |

Публичный интерфейс на админку не ссылается. У админки `noindex, nofollow`.
