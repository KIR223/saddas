# Глоссарий

## Группа

Код учебной группы в шапке Excel и в API, например `ТМ-261` или `ДО-2414/2`. Регулярное выражение на бэкенде: `^[А-ЯЁA-Z]{1,6}-\d{2,4}(?:/\d{1,2})?$` (`backend/app/parser.py`, `GROUP_RE`). Список групп — уникальные `group_name` из таблицы `lessons`.

## Пара

Номер занятия в сетке дня, целое **1–12**. На сервере у пары нет собственного времени: часы начала и конца клиент берёт из сетки звонков по дню недели.

## Шаблон

Недельное расписание из Excel: для каждой группы, дня недели и цвета недели хранятся пары в `lessons`. Один и тот же понедельник зелёной недели повторяется каждую зелёную календарную неделю, пока файл не перезальют.

## Override / замена

Правка **на календарную дату** в `lesson_overrides`: другая пара, другой преподаватель/кабинет или отмена (`cancelled`). Не меняет шаблон. Повторная загрузка Excel overrides **не стирает**.

## `custom`

Флаг в ответе `GET /api/schedule/day`: у группы на эту дату есть хотя бы одна запись в `lesson_overrides`. Не означает, что каждая оставшаяся пара отличается от шаблона.

## Зелёная и красная неделя

Чередование по ISO-номеру недели (`datetime.date.isocalendar().week` / аналог в JS):

- нечётная → `green` / на клиенте `odd`
- чётная → `red` / на клиенте `even`

Функции: `current_week` в `backend/app/week.py`, `getMelmkWeekType` в `frontend/js/models/bells.js`. Переключателя «показать другую неделю» в публичном UI нет: тип недели — информационный бейдж.

Это **не** тема оформления. В названиях палитр слов «Зелёная» и «Белая» нет.

## Сокращённый день

На сервере: дата в `bell_short_dates` и слоты в `bell_short_days`. `GET /api/bells?date=YYYY-MM-DD` тогда отдаёт `kind: "short"`, иначе обычную сетку.

На клиенте есть ещё локальный шаблон `shortDay` в `localStorage` (`melmk_bells_v2`) — он не равен серверному списку дат.

## Кураторский час

Только клиент. Слоты «до первой пары» в пн и/или чт: по умолчанию «Разговор о важном» (пн) и «Россия — мои горизонты» (чт). В SQLite и API звонков этого нет.

## Источник истины

| Что | Где правда |
| --- | --- |
| Шаблон семестра, справочники кабинетов и преподавателей | SQLite после `POST /api/admin/upload` |
| Замены на дату | `lesson_overrides` |
| Регулярные и сокращённые звонки на сервере | `bell_regular`, `bell_short_*` |
| Сетки пн/чт, кураторский час | `localStorage` браузера |
| Кэш публичной страницы | IndexedDB `ScheduleAppDB` + `localStorage` |

## Токен API и логин админки

Две разные вещи. Логин/пароль `/admin/` — PBKDF2 на клиенте (`frontend/js/utils/auth.js`). Запись в БД — заголовок `X-Admin-Token`, значение `ADMIN_TOKEN` на сервере, в браузере ключ `schedule_admin_token`.
