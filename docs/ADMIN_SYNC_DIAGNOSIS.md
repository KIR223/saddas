# Диагностика: замены в админке не видны в публичном расписании

Дата: 2026-10-08

## Цепочка (как было)

1. Админка → мастер «Замены» → `addSubstitution` / `updateSubstitution`
2. `persistSchedule()` → **только** IndexedDB/localStorage браузера админа
3. Публичная страница → `syncFullFromApi` / `fetchSchedule` → пары из **БД API**
4. `applySubstitutions` читает `data.substitutions` из **локального** кэша публичного браузера

## Где рвалась цепочка

**Звено: запись.** Замена никогда не уходила на сервер (`PUT /api/admin/schedule/{date}/pairs/{pair}`).  
Публичный клиент после «Обновить» перезаписывал кэш ответом API без overrides → пометка «Замена» пропадала / не появлялась.

Конфиг подключений / `.env` / данные существующих таблиц **не менялись** (только чтение OpenAPI).

## Типичные причины (проверка)

| Гипотеза | Результат |
|----------|-----------|
| Запрос не уходит | Да: вызова API при сохранении замены не было |
| Пишем в одну таблицу, читаем другую | На клиенте писали в local store, читали с API |
| Несовпадение ключей | После API: ключи `group` + `date` + `pair` (OpenAPI) |
| Кэш SW | Усугублял, но корень — отсутствие записи в БД |
| Разные БД | Публика и админ бьют в один `API_ORIGIN`; локальный IndexedDB у каждого свой |

## Исправление

1. При сохранении замены → `savePairOverride` / `removePairOverride` на даты периода (`dateFrom`…`dateTo` с фильтром по дню недели; без дат — 16 ближайших недель того же дня).
2. Токен `x-admin-token` из `schedule_admin_token` (поле в «Данные»); без токена — явное сообщение.
3. После записи — toast «Сохранено: …», при ошибке — не молчать.
4. Публичный клиент: `hydrateDayOverrides` → `GET /api/schedule/day` → кэш → `applySubstitutions` отдаёт серверные пары с бейджем «Замена».
5. Локальный список замен в админке — журнал UI; источник правды для сайта — БД через API.

Файлы: `frontend/js/api/overrides.js`, `frontend/admin/admin-app.js`, `frontend/js/app.js`, `frontend/js/models/substitutions.js`.

## Миграции SQL

Не добавлялись: на удалённом API уже есть overrides (см. `docs/openapi.json`). Локальный `backend/` в репо — упрощённый; прод использует сервер API.
