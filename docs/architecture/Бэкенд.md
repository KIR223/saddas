# Бэкенд

Пакет `backend/app/`. Точка входа: `uvicorn app.main:app`. При старте `lifespan` вызывает `init_db()` (накатывает миграции SQLite).

Связанные заметки: [[architecture/Данные]], [[architecture/API]], [[processes/Импорт Excel]].

## Модули

| Файл | Роль |
| --- | --- |
| `main.py` | FastAPI-приложение: dotenv, CORS, `lifespan` → `init_db()`, подключение роутеров |
| `migrate.py` | CLI `python -m app.migrate`: те же шаги, что `init_db()`, идемпотентно |
| `migrations/` | Versioner: `schema_migrations` + sql в `migrations/versions/` |
| `routers/info.py` | Публичные `GET /api/info`, `/groups`, `/rooms`, `/teachers` |
| `routers/schedule.py` | `GET /api/schedule`, `/api/schedule/day` |
| `routers/bells.py` | `GET /api/bells` |
| `routers/admin.py` | Мутации `/api/admin/*` (upload, звонки, overrides) |
| `schemas.py` | Pydantic-модели запросов и ответов |
| `security.py` | `tokens_match` / `require_admin` (`X-Admin-Token`) |
| `http.py` | `UTF8JSONResponse`, разбор даты/группы/пары, валидация слотов звонков, сборка payload |
| `db.py` | SQLite: коннект (с миграциями), CRUD расписания, звонков, overrides, `resolve_day` |
| `parser.py` | Чтение `.xlsx`: группы, дни, пары, цвет недели |
| `week.py` | Календарь Москвы, границы недели пн–вс, `green`/`red` по ISO-неделе |
| `catalog.py` | Уникальные кабинеты и ФИО преподавателей из сырого текста ячеек |
| `backend/tests/` | `unittest`: API, парсер, каталог, неделя, миграции |

Ответам JSON выставляется UTF-8 без `\uXXXX` (`UTF8JSONResponse` в `http.py`). CORS: все origin, методы и заголовки.

## Конфигурация

`load_dotenv()` читает `.env` (или путь `ENV_FILE`) и не перезаписывает уже заданные переменные.

| Переменная | По умолчанию | Смысл |
| --- | --- | --- |
| `ADMIN_TOKEN` | `dev` | Значение заголовка `X-Admin-Token` |
| `DATABASE_PATH` | `data/schedule.db` | Файл SQLite; родительская папка создаётся при коннекте; схема — миграциями |
| `ENV_FILE` | `.env` | Откуда читать dotenv |

Пример: `backend/.env.example`.

## Авторизация мутаций

`tokens_match` / `require_admin` в `security.py`. Публичные `GET` без токена. Все `/api/admin/*` зависят от `require_admin` (тот же заголовок `X-Admin-Token`).

## Неделя

`week.py`:

- `now_moscow()` / `moscow_today()` — `Europe/Moscow` (пакет `tzdata` в образе).
- `week_bounds(day)` — понедельник и воскресенье календарной недели.
- `current_week(day)` — `"green"` если `isocalendar().week` нечётный, иначе `"red"`; без даты — московское сегодня.
- `resolve_week("current"|"green"|"red")` — для `GET /api/schedule`.

`GET /api/info` считает неделю и границы на московское сегодня. Клиент для UI использует тот же пояс (`moscowNow`).

## Парсер

`parse_workbook` обходит все листы openpyxl (`data_only=False`, чтобы сохранить заливку).

Правила (детали процесса — [[processes/Импорт Excel]]):

- В верхних 30 строках ищется ряд с максимумом кодов групп.
- Правый столбец объединённого заголовка группы — аудитория, не вторая группа (`subject_columns`).
- Слева от первой группы — день недели и номер пары. Пара обычно занимает две строки.
- Цвет заливки (`classify_rgb`): зелёный → только `green`, красный/розовый → только `red`, серый/белый/нейтральный → обе недели (две записи `Lesson`).
- Текст: первая строка — предмет, остальные — преподаватель (`split_subject_teacher`).
- Аудитория: столбец справа, шаблон `ROOM_RE` (`321`, `с/з`, несколько через запятую).

Пустой список занятий после разбора → HTTP 400. Предупреждения (лист без групп) уходят в `warnings` ответа upload.

## Слияние дня

`resolve_day(group, day, week, on_date)` в `db.py`:

1. Берёт шаблон `lessons` на имя дня и цвет недели.
2. Накладывает `lesson_overrides` этой даты.
3. `cancelled` убирает пару; иначе подменяет subject/teacher/room.
4. Override на пару, которой не было в шаблоне, добавляет занятие.
5. Второй элемент кортежа — `True`, если overrides на дату есть (это `custom` в API).

`day_payload` добавляет к парам `start`/`end` из `get_short_bells` или `get_regular_bells` и поле `revision`.

`replace_day_overrides` сначала пишет переданные пары, затем для каждой пары шаблона, которой нет в запросе, ставит `cancelled=1`.

## Каталог

После upload `room_names` режет кабинеты по `,;` и регистру (`с/з` = `С/З`). `teacher_names` / `split_teachers` вытаскивают «Фамилия И.О.» и канонизируют точки. Тот же канон (`canonicalize_lesson_teacher`, `canonicalize_room`) пишется в `lessons` / overrides и применяется при чтении API, чтобы «Башилова Ю.А» в паре совпала со справочником `Башилова Ю.А.`.

## Ограничения upload

- Расширение `.xlsx` (не `.xls`).
- Не пустой файл, не больше 20 МБ.
- Невалидный zip/xlsx → 400 «не удалось прочитать xlsx».
