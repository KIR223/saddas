# Фронтенд

Статический PWA в `frontend/`. Нужен HTTP-сервер: ES-модули и service worker не работают с `file://`.

Связанные заметки: [[architecture/API]], [[processes/Просмотр расписания]], [[processes/Администрирование]].

## Точки входа

```
frontend/
  index.html              публичный сайт
  admin/index.html        /admin/
  sw.js, manifest.json    PWA
  css/                    токены, layout, темы, moods/
  js/app.js               публичное приложение
  js/config.js            имя приложения, AUTH, ключи LS, палитры
  js/api/                 HTTP, sync, adapt, overrides
  js/models/              schedule, bells, substitutions
  js/views/               экраны
  js/storage/store.js     IndexedDB + localStorage
  js/parser/              локальный Excel (админка без токена)
  js/export/              JSON / CSV / ICS / печать
  admin/admin-app.js
  admin/admin-editors.js
```

## Публичное приложение

`frontend/js/app.js`:

- Вкладки: `home` (расписание), `bells`, `teachers`. Нижняя навигация: Расписание · Звонки · Преподаватели.
- Виды расписания: день / неделя / месяц. Состояние в query (`view`, `day`, `date`, `tab`) и hash группы (`share.js`).
- Группа при входе **пустая** — пользователь выбирает сам (`group-picker.js`). Недавние группы — `groups-pref.js`.
- Тип недели не переключается: запросы шаблона идут с `week=current` на info, а полный шаблон группы тянется как `green`+`red` (`fetchCalendarSchedule`).
- Дни сетки **1–6** (пн–сб). Воскресенье в UI нет.

Экраны: `views/now.js` («Сейчас» и бейдж недели), `day.js`, `week.js`, `month.js`, `bells.js`, `browse.js` (поиск и преподаватели), `empty.js`, `theme-sheet.js`, `export-sheet.js`, `lesson.js`.

Горячие клавиши (см. `frontend/README.md`): `/` поиск, `Esc`, стрелки дня, `T` светлая/тёмная.

## Клиент API

- База: `https://api.melmksch.fvds.ru` (`js/api/config.js`, `API_ORIGIN`). Переопределение: `window.SCHEDULE_API_BASE`.
- Обёртка: `js/api/client.js` (`cache: 'no-store'`).
- Синхронизация: `js/api/sync.js` — bootstrap, одна группа, prefetch остальных (пул 6), полная выгрузка, `uploadAndSync`.
- Адаптер: `js/api/adapt.js` — `ScheduleOut` → `ScheduleData`, `green`/`red` → `odd`/`even`.
- Замены: `js/api/overrides.js` — запись пар на диапазон дат, merge дня в кэш.

## Хранилище

`js/storage/store.js`:

- IndexedDB `ScheduleAppDB` / store `schedule` — основной снимок `ScheduleData`.
- Fallback `localStorage` ключ `schedule_app_v1`, предыдущая копия `schedule_app_prev_v1`.
- Флаги UI: `schedule_app_flags_v1`.

Звонки, тема, аудит, черновик замен — отдельные ключи в `config.js` → `LS`.

## Модель на клиенте

`ScheduleData` (`js/models/schedule.js`): `groups[name].days['1'..'6']` — массив уроков с `pair`, `start`/`end`, `subject`, `teacher`, `room`, `type`, `subgroup`, `week` (`odd`|`even`|`all`). Времена пар по умолчанию различаются для пн, чт и остальных дней (`PAIR_TIMES_MON_THU`, `PAIR_TIMES_THU`, `DEFAULT_PAIR_TIMES`).

Сервер времён не отдаёт: адаптер подставляет слоты `getPairTimesForDay`.

## Темы

Светлая/тёмная (`data-theme`) и настроение (`data-mood`, файлы `css/moods/*.css`). Список `MOODS` в `config.js`. По умолчанию светлая + Индиго. `prefers-color-scheme` не задаёт стартовую тему.

## Админка

Отдельное SPA. Разделы по hash: главная, расписание, замены, преподаватели, кабинеты, звонки, данные, ещё.

Два слоя доступа:

1. Экран логина: PBKDF2-SHA256, 200000 итераций (`AUTH` в `config.js`, `utils/auth.js`). Логин по комментарию в конфиге: `melmk_admin`. 5 неверных попыток → блокировка 5 минут (`localStorage`). Сессия в `sessionStorage`, idle 20 минут.
2. Токен API в разделе «Данные»: `localStorage.schedule_admin_token` → заголовок `x-admin-token`.

Без токена Excel разбирается локально (`js/parser/excel.js` + `mapper.js`), замены не уходят в БД.

## PWA

`initPwa` в `utils/pwa.js`, service worker `sw.js`. Баннеры установки/обновления — флаги store.
