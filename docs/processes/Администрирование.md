# Администрирование

Панель: `frontend/admin/`. В публичном UI ссылки нет. В `<head>` — `noindex, nofollow`.

## Вход в панель

Форма логина проверяет PBKDF2-хэши из `frontend/js/config.js` (`AUTH`, 200000 итераций, 32 байта). Комментарий в коде: логин `melmk_admin`. Пароль в репозитории не хранится, только `passSalt` / `passHash`.

Правила (`utils/auth.js`):

- 5 неверных попыток → блокировка 5 минут (`localStorage`).
- Сессия в `sessionStorage`, продление по активности, выход через 20 минут простоя.

Это **не** авторизация API. Хэши видны в исходниках; обойти экран логина технически можно. Защита SQLite — только `X-Admin-Token`.

Смена логина/пароля: сгенерировать пару `generateHashPair` на странице админки и подставить salt/hash в `config.js`.

## Токен API

Раздел «Данные» (и поле в редакторе расписания). Ключ `schedule_admin_token`. Без него:

- Excel уходит в локальный парсер;
- мастер замен не пишет в БД;
- `saveDatedLesson` бросает ошибку «Нужен токен API».

Токен должен совпасть с `ADMIN_TOKEN` процесса бэкенда (на проде — переменная контейнера).

## Разделы панели

| Hash | Назначение |
| --- | --- |
| `#home` | Счётчики, тип текущей недели (только показ), быстрые действия |
| `#schedule` | Пары выбранной группы **на дату**, запись overrides на сервер |
| `#subs` | Мастер замен на период / 16 недель |
| `#teachers` / `#rooms` | Локальные справочники кэша (`admin-editors.js`); источник правды после sync — API |
| `#bells` | Локальные сетки звонков и кураторский час |
| `#data` | Токен, Excel, JSON, экспорт, журнал аудита |
| `#more` | Прочие ссылки на разделы |

Тип недели в админке переключить нельзя — считается так же, как у студентов (`getMelmkWeekType`).

## Журнал аудита

`frontend/js/utils/audit.js`, ключ `melmk_audit_v1`. Последние записи на экране «Данные». Это лог браузера, не серверный audit trail.

## Типовой рабочий день

1. Войти в `/admin/`.
2. Проверить токен и что публичный API тот (`apiOrigin()`).
3. Новый семестр — [[processes/Импорт Excel]] с токеном.
4. Замена преподавателя / отмена пары — редактор даты или мастер ([[processes/Замены]]).
5. Сказать студентам обновить страницу или подождать следующего захода: hydrate подтянет `/api/schedule/day`.

## Чего панель не делает

- Не является единственным клиентом API: загрузить xlsx можно `curl` с заголовком токена.
- Не синхронизирует кураторский час и сетки пн/чт между браузерами.
- Не меняет формулу зелёной/красной недели.
