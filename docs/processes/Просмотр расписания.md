# Просмотр расписания

Публичный PWA: `frontend/index.html` → `frontend/js/app.js`. Код загрузки: `frontend/js/api/sync.js`, день с заменами: `hydrateDayOverrides` + `fetchAndMergeDay`.

## Цель

Показать актуальное расписание выбранной группы на дату в Москве: шаблон зелёной/красной недели плюс серверные замены этого дня.

## Старт

1. Тема и PWA инициализируются.
2. `syncBootstrap`: параллельно `GET /api/info` и `GET /api/groups`. В кэше появляются имена групп без пар.
3. Группа из hash URL, если она есть в списке, подгружается целиком: `fetchCalendarSchedule` — два запроса `/api/schedule` с `week=green` и `week=red`, слоты сливаются с полем `week: odd|even`.
4. Справочники `rooms`/`teachers` и `GET /api/bells` (без даты) подмешиваются; ошибка каталога не ломает старт.
5. Если группы нет — пустой экран (`views/empty.js`), выдуманных групп нет.

Дальше `syncRemainingGroups` в фоне докачивает остальные группы (до 6 параллельно), чтобы поиск и вкладка преподавателей не ждали клика.

## Выбор группы и вида

Пользователь открывает sheet групп. После выбора: `ensureGroupLoaded`, hash, запись в недавние. Виды:

- **День** — карточки пар выбранной даты, виджет «Сейчас».
- **Неделя** — сетка пн–сб текущей календарной недели.
- **Месяц** — дни месяца; воскресенья без сетки пар.

Состояние в URL: `view`, `day`, `date`, `tab`. Кнопка обновления — `syncFullFromApi`, сброс кэша дней.

## Как собирается день на экране

1. Из кэша группы берутся уроки дня `1..6`.
2. `filterByWeek` оставляет `odd` или `even` по `getMelmkWeekType(дата)`.
3. Для каждой видимой даты (день: выбранная + сегодня; неделя: пн–сб; месяц: все будни месяца) вызывается `GET /api/schedule/day`.
4. Ответ сливается с шаблоном (`mergeDayScheduleOut`): отмены исчезают, отличия помечаются `replaced`.
5. К карточкам могут добавиться кураторский час (`withCurator`) и времена из локальной сетки звонков.

Пока сеть недоступна, показывается кэш IndexedDB. Бейдж «Зелёная» / «Красная» считается на клиенте, не редактируется.

## Другие действия читателя

| Действие | Где |
| --- | --- |
| Поиск по предметам/преподавателям | `/`, `views/browse.js` |
| Список преподавателей | вкладка |
| Сетка звонков и таймер до пары | вкладка «Звонки» |
| ICS / CSV / печать | `export-sheet.js` |
| Светлая/тёмная и настроение | `theme-sheet.js` |
| Поделиться группой | hash в URL |

Читатель не загружает Excel и не ставит замены.
