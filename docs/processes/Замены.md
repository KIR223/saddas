# Замены

Шаблон недели остаётся в `lessons`. На календарную дату действует `lesson_overrides`. Публичная страница не собирает замены из локального массива: она читает уже слитый `GET /api/schedule/day`.

Код: `backend/app/db.py` (`resolve_day`, `upsert_pair_override`, `replace_day_overrides`), `frontend/js/api/overrides.js`, мастер в `frontend/admin/admin-app.js`, редактор дня в `frontend/admin/admin-editors.js`.

## Модель правки

Одна строка: дата + группа + номер пары.

- `cancelled=1` — пары нет в ответе дня.
- Иначе обязателен `subject`; teacher и room могут быть пустыми.
- Пары 1–12. Группа должна существовать в текущем шаблоне (иначе 404).

День целиком (`PUT /api/admin/schedule/{date}`): переданный список — актуальные пары; номера из шаблона, которых нет в списке, записываются как отмены. Другой такой же день недели в следующие недели не меняется.

## Редактор «Расписание»

Админ выбирает группу и **дату** (не «вечный понедельник»). Список пар подгружается через `fetchAndMergeDay`. Сохранение одной пары или отмена — `saveDatedLesson` → `PUT .../pairs/{pair}`. Сброс дня — `DELETE /api/admin/schedule/{date}`. Нужен токен API.

Сообщение в UI: изменения видят все, у кого открыт сайт (после hydrate/refresh).

## Мастер «Замены»

Шаги: Группа → Пара → Преподаватель → Детали → Проверка.

Сохранение:

1. Пишет объект в локальный `scheduleData.substitutions` (черновик, список, undo).
2. Если есть токен — `pushSubstitutionToApi`.

Расширение дат (`expandDatesForSub`):

- Заданы `dateFrom` / `dateTo` — все дни диапазона (макс. 120), при указанном дне недели — только он.
- Иначе — ближайшие **16** недель того же дня недели, включая сегодняшнюю подходящую дату.

На каждую дату уходит отдельный `PUT` пары. Частичный сбой после части дат в коде не откатывает уже записанное.

Удаление из списка при токене вызывает `removeSubstitutionFromApi` (DELETE override на те же даты).

Без токена мастер предупреждает: замена останется только в браузере. Публичные клиенты её не увидят.

## Как это видит студент

`hydrateDayOverrides` запрашивает день для видимых дат и кладёт уроки в `serverDayCache`. Карточка с `replaced` показывает, что пара отличается от шаблона (`original` хранит прежние поля).

Флаг `custom` в API означает «на дату есть overrides», даже если оставшиеся пары совпали с шаблоном (например, отменили одну пару).

## Связь с новым Excel

Повторный upload шаблон меняет, overrides оставляет. Имеет смысл просмотреть замены после смены семестра.
