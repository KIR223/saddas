# Установка на iPhone

1. Администратор публикует сайт по HTTPS в корне домена. `/sw.js`, `/manifest.json` и `/icons/` доступны без входа. Сайт и API используют совместимые HTTPS-домены; публичное расписание не требует учётки.
2. Студент открывает сайт в Safari, выбирает группу и дожидается загрузки. Полезно открыть нужные день, неделю и месяц: замены сохраняются для просмотренных дат.
3. Safari → «Поделиться» → «На экран Домой» → «Добавить». Событие `beforeinstallprompt` на iPhone не требуется.
4. Открыть значок МелМК: приложение запускается без адресной строки. В авиарежиме остаются последнее расписание, просмотренные замены и звонки. Статус сообщает возраст снимка; новые даты могут показывать только шаблон без ещё не скачанных замен.
5. После появления сети нажать обновление. Ошибка не удаляет сохранённый снимок. Новую версию оболочки устанавливать кнопкой «Доступна новая версия — обновить».

Манифест: id/start_url/scope `/`, display standalone; иконки PNG 180/192/512. Apple touch icon 180. Service Worker в корне; приватные API и админка не кэшируются. Очистка данных Safari удаляет офлайн-снимок.

Проверка на реальном iPhone: установить через Safari, закрыть приложение, включить авиарежим, снова открыть значок, проверить день/неделю/месяц и звонки, затем вернуть сеть и обновить. Эмуляция браузера не заменяет этот аппаратный прогон.
