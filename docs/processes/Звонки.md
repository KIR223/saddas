# Звонки

Источник — SQLite сервера: regular, monThu, thursday, shortDay, кураторские часы понедельника/четверга и исключения по датам. Исходные сетки МелМК создаёт миграция; существующая обычная сетка сохраняется.

Администратор открывает «Звонки», редактирует четыре карточки, кураторские часы и даты-исключения, нажимает «Сохранить звонки на сервере». PUT /api/admin/bell-config валидирует пары 1–12, HH:MM, порядок времени и пересечения; всё сохраняется одной транзакцией. Локального автосохранения нет.

GET /api/bells?date=YYYY-MM-DD выбирает исключение, затем понедельник/четверг/обычный профиль. На исключении кураторский час не добавляется. GET /api/bells/config отдаёт полную конфигурацию публичному клиенту. День расписания уже содержит start/end каждой пары; карточки и таймеры используют их. В офлайне используется последний снимок API, а не пользовательский localStorage-профиль.
