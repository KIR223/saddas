# Звонки

Времена пар живут в двух контурах. Они **не совпадают** один в один. Публичный таймер и вкладка «Звонки» опираются на клиентский `BellsConfig` (`frontend/js/models/bells.js`). Сервер отдаёт урезанную модель для общей «регулярной» сетки и сокращённых дат.

## Контур сервера

Таблицы `bell_regular`, `bell_short_dates`, `bell_short_days`. API: [[architecture/API]].

- Одна регулярная сетка на все дни недели.
- Сокращённый день — свой список слотов на `YYYY-MM-DD`.
- Валидация при записи: пары 1–12, уникальные, `HH:MM`, без пересечений по времени.

Публичный `GET /api/bells` без даты отдаёт regular. С датой — short, если дата помечена.

Клиент при sync (`applyApiBells` в `adapt.js`):

- `kind: short` → перезаписывает локальный массив `shortDay`;
- иначе → перезаписывает локальный `regular`.

Сетки `monThu` и `thursday` и блок `curator` с API **не приезжают**.

Админка **не вызывает** `saveRegularBells` / `saveShortBells` из редактора звонков: автосохранение пишет только `localStorage` (`melmk_bells_v2`). Серверные звонки меняются, только если вызвать API отдельно (сейчас в UI раздела «Звонки» этого нет). После bootstrap чужой `regular` с сервера может затереть локальный `regular`, не трогая пн/чт.

## Контур клиента (МелМК)

`defaultBellsConfig` / `getBellsForDay`:

| День | Ключ | Смысл по умолчанию |
| --- | --- | --- |
| вт, ср, пт (и сб как «обычный») | `regular` | 1-я пара 08:30–09:30, пять пар, обед после 3-й |
| понедельник | `monThu` | сдвиг, 1-я 08:45–09:45 |
| четверг | `thursday` | 1-я 09:15–10:15 |
| сокращённый шаблон | `shortDay` | пары по 40 минут с 08:00 |
| пн / чт до пар | `curator` | «Разговор о важном» / «Россия — мои горизонты» |

`getPairTimesForDay` в `schedule.js` дублирует те же три сетки для подстановки `start`/`end` в уроки, пришедшие с API без времени.

Вкладка «Звонки» и виджет «Сейчас» используют `getBellsForDay` + `withCurator`. Сокращённый день в UI — флаг/шаблон клиента, не автоматический список дат с сервера (серверные short-даты публичный экран сам не перечисляет).

## Редактор в админке

Четыре карточки слотов + кураторский час (вкл/выкл, пн, чт, время по дням). Debounce 400 мс в `localStorage`. «Сбросить по умолчанию» — `resetBellsConfig`. Проверка `validateBellSlots` показывает ошибки на странице.

Итог для процесса: чтобы **все студенты** увидели новую общую сетку, её нужно записать в `PUT /api/admin/bells`. Чтобы сдвинуть только понедельник/четверг или кураторский час — правка на устройстве, где открыта админка, и те же ключи LS на устройствах, где уже лежит другой конфиг, не синхронизируются.
