# Импорт Excel

Администратор входит в `/admin/`, открывает «Импорт Excel», выбирает `.xlsx` и режим:

- Заменить весь шаблон — lessons заменяются целиком.
- Добавить только отсутствующие группы — существующие группы и их ручные пары не трогаются.

Перед загрузкой показаны числа всех замен и замен с сегодняшнего дня. Обязательно выбрать: оставить все / снять с сегодняшнего дня (Москва) / снять все. Без выбора сервер отклоняет импорт. Запись шаблона и снятие замен — одна транзакция. При ошибке изменения откатываются.

Ответ показывает diff: созданные группы, записанные/удалённые пары, снятые/оставшиеся замены, предупреждения парсера. Справочники преподавателей и кабинетов сливаются, ручные имена и учётные записи сохраняются.

Файл всегда разбирается серверным openpyxl. Клиентского SheetJS-пути и локального JSON-импорта расписания нет. Excel необязателен: группу и шаблон можно создать вручную.

API: POST /api/admin/upload, multipart file + mode=replace/missing + overrides_policy=keep/future/all. GET /api/admin/import-info возвращает счётчики. Требуется сессия admin.
