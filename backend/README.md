# Расписание колледжа

Бэкенд отдаёт расписание занятий. Администратор загружает файл Excel, пользователи читают его по группе. Отдельного фронтенда нет.

Зелёная и красная недели чередуются по номеру недели года: нечётная — зелёная, чётная — красная. 6 октября 2026 — 41-я неделя, зелёная.

## Запуск для разработки

Команды из папки `backend`:

```bash
cp .env.example .env   # необязательно: без файла токен dev
make dev
```

Сервер: http://127.0.0.1:8000, документация: http://127.0.0.1:8000/docs

Проверки:

```bash
make test
```

## Docker

```bash
docker compose up --build
```

База SQLite лежит в `./data` на хосте. Порт 8000.

## Настройки

| Переменная | По умолчанию | Смысл |
| --- | --- | --- |
| `ADMIN_TOKEN` | `dev` | Заголовок `X-Admin-Token` для загрузки |
| `DATABASE_PATH` | `data/schedule.db` | Файл SQLite |

## Как читается Excel

Файл `.xlsx`, все листы. В верхних строках ищутся коды групп (`ТМ-261`, `ДО-2414/2`). Ниже слева день недели и номер пары. У группы два столбца: занятие и аудитория справа (`321`, `с/з`, несколько номеров через запятую).

Текст занятия: первая строка — предмет, следующие — преподаватель.

Номер пары занимает две строки. Красная или розовая заливка — только красная неделя, зелёная — только зелёная: в ячейке предмет, со следующей строки преподаватель. Без заливки или с серой заливкой занятие идёт на обе недели: предмет в верхней строке пары, преподаватель в нижней. Аудитория стоит в столбце справа и может быть на любой из этих строк.

Повторная загрузка заменяет расписание целиком.

## API

### `GET /api/info`

Текущая неделя, даты понедельника и воскресенья, заголовок семестра, время загрузки.

```bash
curl http://127.0.0.1:8000/api/info
```

### `GET /api/groups`

```bash
curl http://127.0.0.1:8000/api/groups
```

### `GET /api/schedule?group=ТМ-261&week=current`

`week`: `current` (по умолчанию), `green` или `red`.

```bash
curl "http://127.0.0.1:8000/api/schedule?group=ТМ-261&week=current"
```

```json
{
  "group": "ТМ-261",
  "week": "green",
  "days": [
    {
      "day": "Понедельник",
      "pairs": [
        {"pair": 1, "subject": "Физика", "teacher": "Курницкая Т.С.", "room": "307"}
      ]
    }
  ]
}
```

### `POST /api/admin/upload`

Поле формы `file`, заголовок `X-Admin-Token`. В ответе число групп, число записей занятий и предупреждения (лист без групп). Занятие на обе недели считается двумя записями.

```bash
curl -X POST http://127.0.0.1:8000/api/admin/upload \
  -H "X-Admin-Token: dev" \
  -F "file=@schedule.xlsx"
```
