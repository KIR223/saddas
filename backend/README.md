# Расписание колледжа

Бэкенд отдаёт расписание занятий. Администратор загружает файл Excel, пользователи читают его по группе. Отдельного фронтенда нет.

Зелёная и красная недели чередуются по номеру недели года: нечётная — зелёная, чётная — красная. 6 октября 2026 — 41-я неделя, зелёная.

## Запуск для разработки

Команды из папки `backend`:

```bash
cp .env.example .env   # необязательно: без файла токен dev
make dev
```

Сервер: http://127.0.0.1:8000, документация: http://127.0.0.1:8000/docs

Проверки:

```bash
make test
```

## Docker

```bash
docker compose up --build
```

База SQLite лежит в `./data` на хосте. Порт 8000.

## Настройки

| Переменная | По умолчанию | Смысл |
| --- | --- | --- |
| `ADMIN_TOKEN` | `dev` | Заголовок `X-Admin-Token` для загрузки |
| `DATABASE_PATH` | `data/schedule.db` | Файл SQLite |

## Как читается Excel

Файл `.xlsx`, все листы. В верхних строках ищутся коды групп (`ТМ-261`, `ДО-2414/2`). Ниже слева день недели и номер пары. У группы два столбца: занятие и аудитория справа (`321`, `с/з`, несколько номеров через запятую).

Текст занятия: первая строка — предмет, следующие — преподаватель.

Номер пары занимает две строки. Красная или розовая заливка — только красная неделя, зелёная — только зелёная: в ячейке предмет, со следующей строки преподаватель. Без заливки или с серой заливкой занятие идёт на обе недели: предмет в верхней строке пары, преподаватель в нижней. Аудитория стоит в столбце справа и может быть на любой из этих строк.

Повторная загрузка заменяет занятия и справочники кабинетов и преподавателей. Текст занятия в расписании остаётся как в файле. В справочнике преподаватели разбиваются по людям, лишние пробелы и точки убираются: `Башилова Ю.А` и `Башилова Ю.А.` — одна запись `Башилова Ю.А.`. Кабинеты из `502, 204` хранятся по отдельности, `с/з` и `С/З` — один кабинет. Правки на конкретную дату при новой загрузке файла не стираются.

## API

### `GET /api/info`

Текущая неделя, даты понедельника и воскресенья, заголовок семестра, время загрузки.

```bash
curl http://127.0.0.1:8000/api/info
```

### `GET /api/groups`

```bash
curl http://127.0.0.1:8000/api/groups
```

### `GET /api/schedule?group=ТМ-261&week=current`

`week`: `current` (по умолчанию), `green` или `red`.

```bash
curl "http://127.0.0.1:8000/api/schedule?group=ТМ-261&week=current"
```

```json
{
  "group": "ТМ-261",
  "week": "green",
  "days": [
    {
      "day": "Понедельник",
      "pairs": [
        {"pair": 1, "subject": "Физика", "teacher": "Курницкая Т.С.", "room": "307"}
      ]
    }
  ]
}
```

### `POST /api/admin/upload`

Поле формы `file`, заголовок `X-Admin-Token`. В ответе число групп, записей занятий, кабинетов, преподавателей и предупреждения (лист без групп). Занятие на обе недели считается двумя записями.

```bash
curl -X POST http://127.0.0.1:8000/api/admin/upload \
  -H "X-Admin-Token: dev" \
  -F "file=@schedule.xlsx"
```

### `GET /api/rooms` и `GET /api/teachers`

Уникальные кабинеты и преподаватели из последней загрузки.

### `GET /api/bells`

Обычные звонки для всех дней. С `date=YYYY-MM-DD` — сокращённый день, если он задан, иначе обычные. В ответе `kind`: `regular` или `short`.

```bash
curl http://127.0.0.1:8000/api/bells
curl "http://127.0.0.1:8000/api/bells?date=2026-10-08"
```

### `PUT /api/admin/bells`

Записывает обычные звонки. Тело: `{"pairs":[{"pair":1,"start":"08:30","end":"10:00"}]}`. Конец позже начала, слоты не пересекаются, номер пары от 1 до 12.

### `PUT /api/admin/bells/{date}` и `DELETE /api/admin/bells/{date}`

Сокращённый день только на эту дату. `DELETE` возвращает дату к обычным звонкам.

### `GET /api/schedule/day?group=ТМ-261&date=2026-10-05`

Занятия группы на календарный день: шаблон этого дня недели и цвета недели плюс правки только на эту дату. `custom` — были ли правки.

### Правки расписания

Группа передаётся параметром `group`, как в чтении расписания: в коде группы бывает `/`.

`PUT /api/admin/schedule/{date}/pairs/{pair}?group=ТМ-261` меняет одну пару на эту дату: `{"subject":"Химия","teacher":"Петров П.П.","room":"101"}` или `{"cancelled":true}`. `DELETE` того же пути возвращает пару к файлу.

`PUT /api/admin/schedule/{date}?group=ТМ-261` с `{"pairs":[...]}` заменяет день целиком. Пары шаблона, которых нет в списке, на эту дату отменяются. `DELETE` убирает все правки группы на дату. Другой такой же день недели остаётся как в файле.
